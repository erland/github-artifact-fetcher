# DEV-003 – PostgreSQL och automatiska Flyway-migreringar

## Implementerat
- Egen PostgreSQL-databas `github_artifact_fetcher` (skapas som engångsåtgärd i befintlig instans).
- SQL-migreringarna `V1__initial_schema.sql` och `V2__oauth_storage.sql`.
- Separata databasroller: ägar-/migreringsroll och runtime-rollen `github_artifact_fetcher_app`.
- `compose.yml` kör en temporär Flyway-container före tjänsten genom `depends_on: condition: service_completed_successfully`. Flyway körs varje gång Compose-startflödet initieras; databasschemat migreras endast vid behov.
- Den ordinarie Node-containern behöver inte Java och använder endast runtime-kontot.
- Readiness ger HTTP 503 när PostgreSQL eller det migrerade schemat inte är åtkomligt. Health är separat från readiness.
- `package-lock.json` uppdaterad; `npm ci` används vid bygge och i CI.

## Avgränsningar
- Ingen faktisk installation hos användaren eller Coolify-driftsättning är gjord.
- För automatiska migreringar måste installationen startas via `compose.yml` eller motsvarande orchestration med migrering före app. `docker run` av Node-imagen separat garanterar inte migrering.
- Produktionsanslutning, migreringskontot och konfigurationen i Coolify ska verifieras vid DEV-010.
- Skarp ChatGPT-filöverlämning (DEV-001) och OAuth är fortfarande releasekrav.
