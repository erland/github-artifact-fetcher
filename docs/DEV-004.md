# DEV-004 – MCP OAuth: verifierat tekniksteg

## Implementation
- OAuth Authorization Server Discovery och Protected Resource Metadata för /mcp.
- Dynamisk registrering av publika klienter med kontrollerade HTTPS- och loopback-redirects.
- Authorization Code, obligatorisk PKCE S256, validerad client/redirect/resource/scope/state.
- OAuth-koder, access tokens och refresh tokens hashade i PostgreSQL, migrering V3.
- Kortlivade (15 minuter) Bearer access tokens, roterande refresh tokens, transaktionell single-use och återanvändningsskydd.
- MCP-resursen avvisar obehöriga begäranden med WWW-Authenticate och resource_metadata.
- Fel i OAuth-dispatch returnerar felstatus, inte hängande begäranden.
- Ingen upstream-identitet i produktion ännu: auktorisering nekas säkert tills betrodd GitHub-inloggning kopplas in i DEV-005.
- Compose kräver PUBLIC_BASE_URL för OAuth issuer.
