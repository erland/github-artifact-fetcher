# DEV-008 – Repository ZIP med explicit branch, tagg eller commit

## Implementerat
- MCP-verktyget `fetch_repository_archive` tar repository samt `refKind` (branch/tag/commit) och `ref`.
- Kontroll av autentiserad GitHub-användares repositorybehörighet före varje fetch.
- Branch/tagg uppslås via GitHub Git Ref API, commit-SHA via Git Commit API. Annoterad tagg följs ett steg till commitobjekt; andra mål än commit avvisas. Filhämtningen pinnas därefter till verifierad 40-teckens commit-SHA.
- Säker validering av Git-refs (ogiltiga sekvenser, traversal, tvetydiga komponenter och otillåtna tecken).
- ZIP via GitHub `/zipball/{sha}`; högst en 302/307-omdirigering till allowlistad HTTPS-värd, utan vidarebefordrad GitHub-token.
- Nedladdning begränsad till 20 MiB både via deklarerad storlek och under strömning; SHA-256 beräknas över de hämtade ZIP-bytes. ZIP-magic kontrolleras; arkivet packas inte upp.
- Base64-bytes, sha256, filnamn och storlek returneras. Intern ChatGPT-bilaga är fortfarande ej verifierad.
