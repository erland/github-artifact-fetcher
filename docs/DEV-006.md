# DEV-006 – GitHub Release assets

## Implementerat
- MCP-verktygen `list_release_assets` och `fetch_release_asset` med behörighet kopplad till den autentiserade MCP-användarens GitHub-identitet.
- GitHubs Release API via `/repos/{owner}/{repo}/releases/tags/{tag}` och binärt asset-API.
- Kontroll av repositoryåtkomst innan listning eller hämtning, inga opålitliga repositorysökvägar.
- HTTPS-only och explicit tillåtna GitHub CDN-hostnamn för högst en binär omdirigering; GitHub-token skickas aldrig vidare till CDN.
- Högsta tillåtna filstorlek i DEV-006: 20 MiB, kontrolleras både före och under hämtningen; 15/30 sekunders nätverkstimeouts.
- SHA-256 beräknas över mottagna bytes och jämförs mot `sha256:`-digest från GitHub när sådan finns. Filstorleken måste stämma med metadata.
- För filens bytes returnerar verktyget `dataBase64` och metadata. Detta är en begränsad mellantransport för DEV-006, **inte en verifierad ChatGPT-intern bifogad fil**. Större filer och verklig filöverföring förblir öppna accepteranskriterier.
